# ❌⭕ C++ Terminal Tic-Tac-Toe

A clean, light-weight, terminal-based Tic-Tac-Toe game implemented in C++ using Object-Oriented Programming (OOP) principles.

---

## 🚀 Features

* **Interactive Grid:** Displays an updated 3x3 board after every move.
* **Input Validation:** Prevents out-of-range inputs and blocks moves on already occupied tiles.
* **Two-Player Support:** Smooth turn-alternating mechanics for Player `X` and Player `O`.
* **Win & Draw Detection:** Automatically evaluates rows, columns, and diagonals for a victory condition or declares a draw if all tiles are filled.

---

## 🛠️ Requirements

* Any standard C++ compiler (`g++`, `clang++`, or `MSVC`).
* Recommended IDE: **VS Code** with standard C++ extensions.
